# Obsidian GCal Sync

個人用のツールです。作成者本人の Google アカウントだけで使います。

## プライバシーポリシー

- このアプリは、作成者本人の Google カレンダーと Gmail を**読み取るだけ**です。
- 読み取ったデータは、作成者本人の PC の中（Obsidian のノート）にだけ保存します。
- データを第三者へ送ったり、共有したり、販売したりすることはありません。
- 認証の情報は作成者本人の PC の中にだけ保存し、外部へ送りません。

## Privacy Policy

This is a personal tool used only by its author with the author's own Google account.
It only reads the author's Google Calendar and Gmail, stores the data locally on the author's PC,
and never sends, shares, or sells any data to third parties.
